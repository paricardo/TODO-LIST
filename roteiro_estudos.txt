AUTENTICAÇÃO vs AUTORIZAÇÃO

    AUTENTICAÇÃO - A autenticação e usada para verificar a indentidade de um usuário.

        -- EMAIL
        -- SENHA

        --TOKEN

    AUTORIZAÇÃO - A autorização é usada para determinar quais ações um usuário pode realizar após o mesmo, já ter sido autenticado.

        VITOR -> INICIA UMA SESSÃO
                E-mail e SENHA -> token (uma sequencia de caracteres é uma sequencia criptografada com os dados do usuário JWT)
                Cadastrar um novo usuário administrador ....
                Quando o token chegar junto com os dados na rota de novo usuário  a rota vai pegar os dados do usuário que está 
                solicitando aquela ação  e identificar se o token é válido, ver se o usuário tem permissão.

                ROTA PROTEGIDA
                    TOKEN
                    VERIFICAR SE O TOKEN É VÁLIDO 
                    DESCRIPTOGRAFAR O TOKEN E PEGAR OS DADOS DO usuário
                    VAI VERIFICAR SE AQUELE USUÁRIO TEM AUTORIZAÇÃO PARA FAZER AQUELA ação
